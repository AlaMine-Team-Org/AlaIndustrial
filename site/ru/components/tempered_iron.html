Закалённое железо

alaindustrial:tempered_iron
КомпонентыРеализованоcomponentmetalstempered-iron

Сводка

Закалённое железо — слиток, который получают переплавкой одного ванильного железного слитка. Рецепт строго 1:1, но на выходе уже другой материал — «закалённое» железо, из которого получаются предметы чуть лучше железных.

Это материал-источник для всей одноимённой линии мода: пяти инструментов (кирка, топор, мотыга, лопата, меч), набора брони из четырёх предметов и компактного блока 9:1. Сам по себе слиток энергии не хранит — это просто ингредиент для крафта, как ванильное железо.

Мини-пример: закиньте стэк железных слитков в доменную печь — получите стэк закалённого железа, а из него скрафтите кирку из закалённого железа: копает чуть быстрее и живёт дольше ванильной железной.

Энергия

Энергии не использует — ни хранит, ни передаёт.

Как используется

Материал для крафта и ремонта. Из него собираются инструменты из закалённого железа (кирка/топор/мотыга/лопата/меч), соответствующий набор брони и блок закалённого железа (9:1 — для компактного хранения и построек). Инструменты и броня этой линии чинятся в наковальне теми же слитками — так же, как ванильные железные вещи чинятся железом.

Свойства блока

Не применимо (предмет). Стак: 64.

Рецепты

Слиток получается переплавкой — три способа, все 1:1 (один железный слиток → один закалённый):

Ванильная печь — медленный повседневный путь; даёт немного опыта, как переплавка руды. Доменная печь (blast furnace) — вдвое быстрее печи, тот же небольшой опыт (как всегда для доменной печи). Электропечь мода — работает на EU/FE вместо топлива, без опыта (опыт — ванильная механика печи; электропечь его не выдаёт).

Обратный путь — разбор материального блока (1 блок → 9 слитков) — описан на странице блока закалённого железа.

Прогрессия

Материал без собственного тира. Естественный шаг над ванильным железом: как только вы плавите железо массово, его можно закалить и собрать экипировку, которая чуть лучше железа по всем осям, но при этом не перекрывает алмаз по доступу к блокам.

Связанное

Блок закалённого железа — компактная форма 9:1. Инструменты из закалённого железа — главный потребитель слитков. Электропечь — способ получения на EU/FE. Формы материалов — более широкая цепочка руда → пыль → слиток.
