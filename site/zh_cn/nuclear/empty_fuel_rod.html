燃料包壳

alaindustrial:empty_fuel_rod
核能设施已实现nuclearreactorfueluraniumrecycling

概览

燃料包壳就是没有铀的燃料棒：屏蔽底座上的铁制外套，除了燃料以外一切 照旧。它有两个来源——工作台合成，以及在燃料棒交出自己的 144 000 EU/FE 之后由 反应堆柱归还——而两者都通向同一个配方：包壳 + 一份浓缩铀 = 装料的燃料棒。

在它出现之前，烧尽的燃料棒会直接消失，因此每一次续料的成本都和第一次完全一样：三块铁锭、四粒铁粒 和一块屏蔽板——也就是每根燃料棒永远要花掉三分之一块钯锭。钯只能在下界开采，而运行在 HV 上限的 反应堆每小时要吃掉 256 根燃料棒。包壳把这条支出变成了闭环：包壳只合成一次，之后要买的只有铀。

它从哪里来

途径发生了什么
3×3 合成每次 ×1——没有燃料的外套
柱中烧尽的燃料棒燃料棒耗尽耐久的一刻，反应堆柱就地把它换成包壳
空手右键反应堆柱包壳优先交还，排在装料燃料棒之前
破坏反应堆柱全部内容物掉落，包壳也在其中

料架不会自己丢掉包壳：烧尽的燃料棒仍留在原位，并且从外面看得见——它是暗的，与发亮的装料燃料棒 不同。跑完一轮的柱子在大厅另一头也看得出是跑完了，这本身就在告诉玩家那里有东西可取。

它到哪里去

燃料包壳 + 浓缩铀 → 燃料棒

配方是无序的：两件物品放进网格的任意格子。这是核能支线中刻意做得最省心的配方——给反应堆续料一次就是 几十根，若要求每根都摆一次 3×3，那等于因为规模而惩罚玩家。

它可以插回柱中

包壳可以重新放回反应堆柱——这不是无用操作，而是把包壳存放在它们 将会派上用场的地方。柱子区分两个计数：一共插了多少根，其中多少根带铀。反应堆只数后者：空包壳 既不产出 EU/FE，也不产热，更不参与相邻加成。

运行在 HV 上限的反应堆每小时烧掉 256 根燃料棒。两列的差别是这样读的：

不回收包壳——每小时 256 块屏蔽板，也就是每小时约 85 块钯锭，等于一小时之内要去下界好几趟； 回收包壳——首批投入之后钯的消耗为 0；合成了多少包壳，就有多少在循环里转。

循环里需要多少包壳，取决于的不是功率而是房间大小：每个插槽一根。3×3 一层（九根柱子）需要 36 个 包壳，塞满的 3×3×3 房间需要 108 个。此后它们自己回来。

配方

合成：每次 ×1。

N I N N = 铁粒 ×4
I I I = 铁锭 ×3
N P N P = 屏蔽板 ×1

这正是从前的燃料棒配方，只是中间空着：外套、铆钉和屏蔽底座，除了铀芯块以外一应俱全。配方因此 不言自明：中间那格由第二个无序配方来填。

续料：无序配方，包壳 + 浓缩铀 → 燃料棒。

进阶

等级：无（该物品不涉及能量）。 需要：屏蔽板——也就是钯，也就是下界。不需要铀：在找到第一条铀矿脉之前就可以先把包壳做好。 解锁：不再消耗钯的反应堆续料。第一批包壳是燃料循环唯一一次索取钯。
