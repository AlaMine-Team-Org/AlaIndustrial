# Development direction

Ala Industrial develops Minecraft 26.3 and continues supporting Minecraft 26.2, on Fabric and
NeoForge. Both game versions receive features and fixes; their API adaptations live in separate branches.

Development focuses on industrial progression, automation, energy networks, processing machines,
and compatibility across the supported game and loader combinations. Planned work is not a promise
of availability in a particular download. See the [player guide](https://alamine-team-org.github.io/AlaIndustrial/)
for documented systems and [release notes](https://github.com/AlaMine-Team-Org/AlaIndustrial/releases)
for changes available in published builds.
